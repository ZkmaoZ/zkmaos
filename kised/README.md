# KISED 발산 스캔 보관소

본 보관소는 **외부 제출용이 아니다**. Claude 웹(Research 토글)에서 돌린
트렌드 스캔의 4분면 매트릭스를 누적·버전 관리하기 위한 개인 참고용
저장소다.

## 분업 (중요)

- **스캔 본체** → Claude 웹 + **Research 토글**에서 실행.
  Claude Code의 `web_search`는 단발 검색이라 Research의 다단계 스캔과
  다르다. **혼용 금지.**
- **누적·보관** → 이 리포(여기).
- **외부 브리프 승격** → `kised-research-brief-v0` Skill로 이동, 1차
  출처 재검증 후에만 정량값 인용.

## 사용 절차

1. Claude 웹 Project에 `kised-discovery-scan-v0` Skill을 지침으로 부착.
2. 세션 1회 = 스캔 1회. Research로 후보를 8매체 × 6시그널에 매핑.
3. 결과를 `scripts/new_scan.sh` 로 생성한 오늘자 파일에 붙여넣기.
4. 커밋·푸시.

```bash
bash scripts/new_scan.sh
```

## 축 변경 금지

`axes.yml`의 8매체·6시그널·임계값(2/2)·4분면·자본 티어는 **고정**이다.
축을 바꾸면 누적된 모든 스캔이 비교 불능이 된다. 변경이 필요하면 별도
브랜치를 파고 *축 변경 사유서*를 README에 남길 것.

## Hard Rules (Skill 원문 요약)

- 스캔 등급 산출물을 외부 등급으로 표기 금지.
- 정량 주장에는 반드시 `[매체 — 스캔, 미재검증]` 또는 `[미확인]` 태그.
- 머리말 스탬프 고정:
  **"리서치 등급: 개인 참고용 · 스캔. 외부 인용 전 1차 출처 재검증
  필수. 부정신호·v3 코딩 미적용."**
- 매 출력에 **반증 후보 1개**와 **무행동 옵션**을 의무 기재
  (선택편향 차단).
- 말미에 **한계** 절 필수: 매체 편향 / 자본 추정 편차 / 시점 한계.

## 졸업 게이트 (외부 브리프로 승격할 때)

1. `kised-research-brief-v0`의 Step 1(출처 수집) + Step 3(외부 제출
   검증)을 통과할 것.
2. **스캔 등급 정량값을 외부 문서에 그대로 인용 금지** — 1차 출처
   재확인 후에만 승격.
3. 발산(개인·미재검증) → [재검증 게이트] → 수렴(외부·검증). 두 등급은
   별개로 취급.

## 본 보관소가 처리하지 않는 것

- 외부 제출 초안 → `kised-research-brief-v0`
- 교정·윤문 → `kised-editor-mode`
- 슬롯·부정신호 → `kised-slot-coding-v3`, `kised-negative-signal-v3`
- 진입 분야 최종 선택·정책 권고 → 우성 직접 결정
